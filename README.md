# VirtualSphereProject

## Description
VirtualSphereProject est une **application web interactive** pour la **gestion visuelle du personnel** qui facilite la gestion visuelle du personnel sur un **plan d’étage en temps réel**. 

## Fonctionnalités
- **Gestion visuelle du personnel** : ajout, déplacement, suppression d’employés  
- **Validation des données** : contrôle des formats, dates et prévisualisation des photos  
- **Règles métier** : accès aux zones selon les rôles des employés  
- **Plan d’étage interactif** avec 6 zones principales  
- **Liste “Unassigned worker”** pour gérer les employés avant leur affectation
- Interface moderne et **responsive** (mobile, tablette, desktop)
